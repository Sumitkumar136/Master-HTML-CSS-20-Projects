# **Todo List – Web Project**

A clean and visually appealing **Todo List UI** built using **HTML & CSS**.
This project demonstrates task listing, completion states, and action icons in a modern layout.

---

## 🔗 **Live Demo**

👉 **[Click Here to View](https://9-todo-list.vercel.app/)**

---

## 📌 **Features**

* Modern and clean UI design
* Task completion using checkboxes
* Completed task styling (strike-through)
* Edit and delete action icons
* Responsive layout

---

## 🛠️ **Technologies Used**

* **HTML5**
* **CSS3**
* **Google Fonts (Roboto)**

---

## 📁 **Project Structure**

```
|-- index.html
|-- style.css
|-- edit.svg
|-- delete.svg
```
